# ESStyleFileManager

A GPL-3.0 derivative build based on [Material Files](https://github.com/zhanghai/MaterialFiles), customized with an ES-style workflow and additional Android storage access shortcuts.

## Goals

- Preserve Material Files' local/network file-management features.
- Provide an ES-style home/dashboard and navigation workflow using original code and assets.
- Show hidden files by default.
- Provide explicit SAF/document-tree shortcuts for Android/data and Android/obb where supported by the device's DocumentsUI implementation.
- Keep Root/Shizuku optional rather than required.
